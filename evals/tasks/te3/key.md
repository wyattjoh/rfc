# te3 — resource parameter URI

1. The value MUST be an absolute URI as specified by RFC 3986 §4.3 — **RFC 8707 §2**, L146–L149.
2. The URI MUST NOT include a fragment component — **RFC 8707 §2**, L148–L150.
3. The URI SHOULD NOT include a query component, but the RFC recognizes useful and necessary cases for one — **RFC 8707 §2**, L150–L154.

Note: Do not turn the query-component SHOULD NOT into a prohibition; a URL is not the only possible absolute URI.
