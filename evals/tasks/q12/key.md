# q12 — URI scheme ABNF (RFC 3986)

1. `scheme = ALPHA *( ALPHA / DIGIT / "+" / "-" / "." )` — **RFC 3986 §3.1** (L921).
2. **Case-insensitive**; canonical form is lowercase — **§3.1** (L912–918).
3. Status: **Internet Standard (STD 66)** (L9; rfc3986.json). "Standards Track"
   (the header's Category) also accepted; Proposed/Draft Standard is wrong.
